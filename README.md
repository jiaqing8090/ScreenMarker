# 屏幕画笔 ScreenMarker

Android 悬浮标注工具，配合系统自带录屏使用。当前版本提供：自由画笔、箭头、椭圆圈选、矩形框选、颜色轮换、单笔/单擦、撤销最近一笔、一键全擦、收起/展开工具栏、关闭悬浮窗。

## 使用
1. 安装 APK 并打开「屏幕画笔」。
2. 点击「开启悬浮画笔」，按系统提示授权“显示在其他应用上层”。
3. 启动系统录屏，在浮动工具栏选画笔或图形；「单擦」选择后，在要删除的笔迹/图形附近点擦即可；「撤销」移除最后添加的一项；「全擦」清空所有标注。
4. 「收起」隐藏按钮栏但保留屏幕标注，点右侧小标签恢复；「关闭」退出标注。

## 构建
GitHub Actions 在 push 或手动触发后构建 debug APK，产物名 `ScreenMarker-debug-apk`。

## 权限/兼容性
需要 Android 6.0+ 悬浮窗授权。部分厂商系统的录屏/安全策略可能不录制悬浮窗；请先录一段短视频确认。悬浮层全屏接收触摸，因此触屏幕内容时可能被画笔层拦截；使用「收起」后再操作底层应用。
